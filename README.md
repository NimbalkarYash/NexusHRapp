# NexusHR 🚀

🔗 **Live Demo:** https://nexushr-yash.netlify.app/

---

## 📌 Overview

NexusHR is a full-stack serverless employee management system built using AWS cloud services. It provides secure authentication, employee data management, and profile image handling through a modern web interface.

This project demonstrates practical implementation of cloud-native architecture using scalable and managed AWS services.

---

## 🛠️ Tech Stack

### ☁️ AWS Services

* **AWS Cognito** — Authentication & user management
* **AWS Lambda** — Backend compute (serverless functions)
* **API Gateway** — REST API endpoints
* **DynamoDB** — NoSQL database for employee data
* **S3** — Storage for employee profile images

### 💻 Frontend

* HTML
* CSS
* JavaScript

---

## ✨ Features

* 🔐 Secure login using AWS Cognito
* 👥 View all employees in a clean directory UI
* ➕ Add new employees with details & profile photo
* ✏️ Update employee information
* 🗑️ Delete employees by ID
* 🖼️ Upload and display profile images from S3
* ⚡ Fully serverless architecture

---

## 🧠 Architecture

The application follows a serverless architecture:

Frontend (Netlify) → API Gateway → Lambda → DynamoDB
↘ S3 (images)
↘ Cognito (auth)

---

## 🚀 Deployment

* **Frontend:** Hosted on Netlify
* **Backend:** AWS Lambda + API Gateway
* **Database:** DynamoDB
* **Storage:** S3
* **Authentication:** AWS Cognito
